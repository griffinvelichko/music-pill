Strobe

A sample <music-pill> for one Spotify track. Title, artist, and artwork were filled by scripts/generate-sample-track.mjs, which runs music-pill-resolve on the track link. Regenerate with npm run build && npm run generate:sample-track.

This page plays a generated test tone, not this song. audio-src points at fixtures/audio/test-tone.wav, made by scripts/generate-fixtures.mjs. A real deployment should point audio-src at a file the site owner has the rights to play, and that file should be the same recording the pill links to. You are responsible for the rights to the song you display and the audio you attach.
