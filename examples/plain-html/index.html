Plain HTML example

This page shows a link-only pill: it links to the song on Spotify and plays no audio, so it has no sound button.

To add background audio, add audio-src pointing at a file of the same recording that you are licensed to play on your site. Linking to Spotify grants no audio rights.

Run npm run build && npm run serve and open http://127.0.0.1:4173/examples/plain-html/.
