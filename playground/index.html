Audio (optional)

Test tone: audio engine check

This mode plays a quiet generated test tone (440 Hz + 660 Hz) from fixtures/audio/test-tone.wav. It is not a Spotify recording. The pill's link points to a placeholder track ID that does not exist on Spotify, and no snippet is generated. Use this mode only to hear fades, looping, mute and blocked-autoplay behaviour.

Generated tone: one source, several sources, error

These cases play fixtures/audio/test-tone.wav, a tone generated in this repo, or they refuse it on purpose. They are not Spotify recordings. The link uses a placeholder track id. You still need rights to any song and audio you use on your own site.
